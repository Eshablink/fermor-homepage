# Fermor Homepage — Product Design Assignment

A responsive Next.js homepage concept built around **Your money, in context.**

## Product thinking
The experience follows **See → Understand → Decide → Grow**. Financial data is treated as the product language rather than decoration, and the interactive future-value simulator demonstrates how a user can explore a decision rather than simply read marketing copy.

## Design decisions
- Editorial fintech visual system: paper background, ink typography and one green accent.
- Data-first storytelling instead of generic fintech/AI illustrations.
- Restrained motion and interaction to keep the experience trustworthy and human.
- Responsive layouts designed for both desktop and mobile.

## Stack
Next.js 15 · React 19 · TypeScript · CSS
